# @bugsee/types

TypeScript types shared across the Bugsee JavaScript SDK packages. It contains no runtime code.

Part of the Bugsee JavaScript SDK (public beta, 0.1.0-beta.x).

This is an internal building block of the Bugsee SDK, not intended to be installed directly. Install `@bugsee/bugsee` instead.

## What it contains

- The service, extension and hook name mappings that other packages extend by declaration merging.

It is used by `@bugsee/core`, `@bugsee/protocol`, `@bugsee/capture` and `@bugsee/performance`. Its API is internal and may change between releases.
